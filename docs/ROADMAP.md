# 로드맵 — 쇼츠 자동화

## 🎯 GOAL
유튜브 쇼츠(메인: **과학·생활 팁**)를 자동 생성해 게시까지 이어지는 시스템을 만들고, 하루 2편 운영으로 채널을 성장시켜 **YPP Tier 1(구독자 500 + 90일 쇼츠 300만 조회 또는 시청 3,000시간)** 을 1차 달성한다.

**원칙**: 스크립트 사람 검수 유지 · 영상마다 변주 · 사실 주장은 출처 필수 · 사용권 확인된 소스만 · 밈/썰 쇼츠는 추후 확장
