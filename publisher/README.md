# 발행 편성표 (yt-publisher)

쇼츠(드라마/영화·쇼핑·유머·과학) 영상을 **예약 자동 발행**하고 **조회수 통계를 추적**하는 로컬 웹 앱입니다. 롱폼은 설정만 준비되어 있고 기본으로 꺼져 있습니다.
내 컴퓨터에서만 열리고(127.0.0.1), 영상·로그인 정보는 이 폴더의 `data/` 밖으로 나가지 않습니다.

## 실행
- **Mac**: `start.command` 더블클릭 (처음엔 우클릭 → 열기). 터미널이면 `bash start.sh`
- **Windows**: `start.bat` 더블클릭
- Python 3.9 이상이 필요합니다. 첫 실행 때 부품 설치에 1~2분 걸리고, 브라우저가 자동으로 열립니다(주소 `http://127.0.0.1:8765`).
- 창을 닫으면 앱도 꺼집니다. 이미 업로드된 예약은 유튜브 서버가 시각에 맞춰 공개하므로 앱이 꺼져 있어도 공개됩니다.

## 처음 써보기 (데모 모드)
기본은 **데모 모드**입니다. 가짜 업로드·가짜 조회수라서 구글 설정 없이 화면을 다 써볼 수 있습니다.
쇼츠 탭 → 카테고리 선택 → 영상 올리기 → 예약 → 편성표에서 확인 → 통계 탭에서 '지금 수집'.

## 영상 자동 제작 (과학 카테고리)
쇼츠 → 과학 탭의 '영상 자동 제작'에 주제 한 줄을 넣으면, 옆 폴더의 제작 프로그램(`main.py`)이 스크립트 작성 → 음성 → 영상 소스 → 편집까지 해서 초안으로 넣어줍니다.
- 이 폴더(`publisher/`)가 제작 프로그램 폴더 안에 있으면 자동으로 찾고, 따로 두었다면 설정 탭에서 '제작 폴더'를 지정하세요. 제작 프로그램 쪽에 `.env`(API 키)가 있어야 합니다.
- '스크립트만 먼저'를 켜 두면 글만 만들어 보여주고, 확인한 뒤 같은 글로 영상을 만듭니다.
- 영상 속 사실 주장은 **사실 확인** 목록으로 들어가며, 출처를 직접 확인해 모두 체크해야 예약됩니다. 쓴 영상 소스와 라이선스도 영상 상세에 기록됩니다.
- 지금은 과학 카테고리만 자동 제작을 지원합니다. 나머지 카테고리는 영상을 직접 올려주세요.

## 영상 넣는 법
1. 화면에 끌어다 놓기, 또는
2. `data/inbox/shorts/<카테고리>/` 폴더에 파일 넣기 (`drama_movie`, `shopping`, `humor`, `science`). 롱폼은 `data/inbox/longform/`.
   같은 이름의 `.json`을 옆에 두면 제목·설명 등을 미리 채웁니다: `{"title":"","description":"","tags":["a"],"affiliate":false,"rights_confirmed":false,"synthetic":false}`

## 실제 유튜브 발행 연결
1. Google Cloud에서 프로젝트 → **YouTube Data API v3** 사용 설정 → OAuth 동의 화면 → **데스크톱 앱** OAuth 클라이언트 만들기 → JSON 다운로드. (자세한 순서: 저장소의 `docs/YOUTUBE_SETUP.md`)
2. 설정 탭에서 그 JSON을 올리고 → '구글 로그인' → 발행 방식을 '실제 발행'으로 저장.
3. 동의 화면이 '테스트' 상태면 로그인이 7일마다 풀립니다. 그때는 '구글 로그인'을 다시 누르세요.
4. 인증이 안 된 API 프로젝트는 업로드한 영상이 비공개로 잠길 수 있다는 보고가 있으니, 처음엔 영상 1개로 시험 업로드해서 확인하세요.

## 꼭 알아둘 것
- **드라마/영화**: 타인 영상·음악은 저작권 신고·수익 제한 대상입니다. 권리 확인 체크 없이는 예약되지 않습니다.
- **쇼핑**: 제휴·협찬이면 설명에 '광고/협찬/제휴' 문구가 있어야 예약됩니다. 유튜브의 '유료 광고 포함' 항목은 API가 거절하면 Studio에서 직접 체크해야 합니다(로그에 표시).
- 쇼츠 길이 상한(기본 180초)은 설정으로 바꿀 수 있고, 최신 규정은 직접 확인하세요.
- 업로드 하루 한도(기본 20개)를 넘기면 다음 날로 밀립니다. 통계 조회수 집계 기준은 2026-08-24에 유튜브가 바꿨습니다.
